# 🚀 ShaneCodes Windows Utilman

**Your Windows, Your Control** — A comprehensive system utility for installing software, applying tweaks, managing updates, and more.

## ✨ Features

- 📦 **Software Installation** : Install your favorite apps with one click
- ⚡ **System Tweaks** : Apply performance, privacy, and interface tweaks
- 🔧 **Update Management** : Configure and manage Windows Updates
- 📊 **System Information** : View detailed system specs
- 🚀 **Preset Engine** : Apply Standard, Minimal, or Advanced configurations
- 🔄 **Self-Updating** : The utility can update itself
- 📝 **Logging** : Detailed logs for troubleshooting
